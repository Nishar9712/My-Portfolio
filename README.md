## 💻 How to Run Locally

### Option 1: Run with Streamlit (Recommended)
1. Clone the repository:
   ```bash
   git clone https://github.com/Nishar9712/My-Portfolio.git
   cd My-Portfolio
   ```
2. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```
3. Launch the app:
   ```bash
   streamlit run app.py
   ```
4. Open [http://localhost:8501](http://localhost:8501) in your browser.

### Option 2: Run directly in Browser
Open `index.html` directly in any web browser without needing Python.
